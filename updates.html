Changelog

Updates

A short, plain-English record of what changed on this site.

Site launch

Nov 13, 2026

The first public version of the BIM Reference Library went live, with five guides — Modeling, Revit add-ins, Coordination & clash, Spooling & fabrication, and Visualization — plus this updates page. Popularity captions were researched in November 2026. See CHANGELOG.md in the repository for sources.

Product cards render fix

Nov 13, 2026

Fixed a JavaScript typo that left section pages without their product cards after the first deploy. Hover glow now also applies to those cards, not only the homepage section tiles.

Custom domain and Git auto-deploy

Nov 13, 2026

The site now lives at bimchart.net. The pages.dev address still works; search engines are pointed at the .net copy. Pushing to the GitHub main branch now publishes automatically.

Auto-deploy on push confirmed

Nov 13, 2026

The Cloudflare Workers and Pages GitHub App now has access to this repository, so a push to main publishes the site without a manual deploy.

Ko-fi footer

Nov 13, 2026

Every page now has the same Ko-fi support line used on ammochart.net.

Footer matches other sites

Nov 13, 2026

The page footer is now only the shared Ko-fi line used on ammochart.net and Marcus's other sites. The homepage also has the "Last updated / See what changed" line, like ammochart's home page.

Cost ratings on every card

Nov 13, 2026

Each product card now has a Cost row on a Free / $ / $$ / $$$ / $$$$ scale, with a caption citing a published price or marking the band as an estimate. You can sort each guide cheapest-first or priciest-first.

Comparison charts, not more cards

Nov 13, 2026

Section pages are now compact, horizontally scrollable comparison charts in the same style as the ammo reference charts: sticky headers, filter chips, click-to-sort columns, and a small visual in the first column. That visual is the product’s desktop or app icon when we could find an official one, or a generated initials tile if we could not.

Official icons and learning-curve header

Nov 13, 2026

Replaced generated initials tiles with official app icons or official product/vendor marks on all five section charts wherever those assets could be found. The Learning curve column now notes “editorial rating” once in the header instead of repeating “editorial” on every row.

Scanning hardware and AEC drones

Nov 13, 2026

Added two new guides — Scanning hardware and Drones for AEC and BIM — each with a homepage tile and the same scrollable comparison chart used on the software sections. First-column visuals are official product photos when we could fetch them, or a generated illustration if not. Popularity is editorial on these pages (the Confluence 2025 survey is software-only). Cost is a purchase-price band with official or reseller citations, or an estimate when the vendor only quotes.
